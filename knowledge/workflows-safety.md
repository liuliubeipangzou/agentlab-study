# 工作流与执行安全

工作流 DAG 用节点表示任务，用有向边表示依赖。没有依赖的节点可以并行执行，但并发数量应有限。节点失败后，依赖它的节点跳过，独立分支仍可完成。自动重试只适合幂等操作。

多 Agent 可以采用分工：研究员拥有检索工具，计算员拥有计算器，汇总节点消费两者结果。每个 Agent 拥有自己的会话上下文，工具按职责授权。

写入文件和长期记忆需要人工审批。批准应绑定具体工具调用及参数，不能作为永久写入授权。程序中断时，外部副作用可能已发生；恢复不应盲目重放工具。

工具工作目录限制不是操作系统沙箱。自定义 Python 处理器被视为可信代码，执行不可信代码需要进程或容器级隔离。超时协程不能强行终止已经运行的线程。
