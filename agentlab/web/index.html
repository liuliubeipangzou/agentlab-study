  1. 运行模式选择“真实模型”。
  2. 填写支持工具调用的模型名称和接口地址。
  3. 输入密钥，保存并测试连接。
  4. 新建对话，用自然语言提出任务。

连接测试会向已配置的服务发送一条简短请求，可能产生 API 费用。
