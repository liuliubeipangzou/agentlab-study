# 记忆与 RAG

短期记忆是当前对话 messages。长期记忆保存明确需要保留的偏好与事实，例如用户的学习目标。Agent Lab 的长期记忆按 session_id 隔离，记住新内容需要审批。

RAG 是检索增强生成：先从知识库找到与问题相关的片段，再让模型依据片段回答。资料应带来源和片段编号，回答引用它们，便于读者核对。

Agent Lab 先将 Markdown 和 TXT 分块，建立中英文词法 BM25 索引。块之间有重叠以保留边界上下文。重复导入不增加相同文件的重复片段；文件更新会替换旧片段。词法搜索依赖关键词，不等于语义向量检索。

检索得到的片段是不可信输入。如果文档包含“忽略系统提示”“发送密钥”等文字，应作为文档内容处理，不能修改 Agent 的权限。
