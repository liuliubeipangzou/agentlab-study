# 本地浏览器学习界面

界面与 CLI 使用同一套 Python Agent、工具注册表和 SQLite 存储。无需安装前端依赖、
运行构建命令或使用外部 CDN；Python 3.9+ 即可启动。

## 打开与关闭

在 macOS 中双击项目根目录的 **`启动 Agent Lab.command`**。它会先进入项目目录，
再使用系统的 `python3` 启动服务，并打开 [本机界面](http://127.0.0.1:8765/)。
终端窗口是本地服务的运行窗口，请在使用期间保留。

重复双击时，启动器会检查 `/api/health` 是否精确返回 Agent Lab 的服务标识。
如果同一端口已运行 Agent Lab，就打开已有服务，沿用该服务的数据目录和配置；
如果由其他应用占用，或无法确认服务身份，就提示错误，不会结束其他应用或另开服务。

在运行服务的终端按 **Control+C** 停止服务。仅关闭浏览器标签页不会停止 Python 服务。
对话中的“停止运行”用于取消当前任务，也不会退出服务。重启后会话和知识库仍在，
但通过界面输入的 API Key 需要重新填写。

命令行等价入口：

```bash
python3 -m agentlab serve --open
```

修改端口或数据目录时，全局参数放在 `serve` 之前：

```bash
python3 -m agentlab --data-dir .state-demo --workspace my-files serve --port 9876 --open
```

服务只监听 `127.0.0.1`。双击启动器默认使用 8765；自定义端口时使用终端中显示的地址。

## 第一次学习

进入“对话工作台”，点击“新建对话”，在离线 Demo 模式发送：

```text
/calc (20 + 1) * 2
```

回复会包含 `42`。通过“轨迹”观察模型调用、计算器执行和结果返回，在“消息”中
查看工具结果如何进入上下文。Enter 发送，Shift+Enter 换行。侧边栏中的最近对话
可以继续打开，已有消息和检查点会从本机 SQLite 恢复。

Demo 是确定性的规则模拟器。普通自然语言会显示学习指南；需要开放式问答和
自然语言工具决策时，在“设置”中连接真实模型。

## 模型设置与 Key

“设置”提供模型模式、模型名、API 根地址和 API Key。选择真实模型模式后，填写
支持函数工具的 OpenAI 兼容 Chat Completions 服务，点击“保存配置”，再用
“测试已保存的连接”确认。连接测试会向保存的端点发送实际请求；使用真实模型时
由对应服务计费。

DeepSeek 可使用模型 `deepseek-flash` 和根地址 `https://api.deepseek.com`。
框架对这个官方主机自动发送 `thinking: {"type": "disabled"}`，保持当前工具消息
协议一致。其他服务不会收到这个专用参数。模型兼容范围见 [模型适配器](providers.md)。

配置保存行为：

- 模型模式、模型名、API 地址等非敏感选项保存在 `.agentlab/web-settings.json`。
- 通过页面提交的 API Key 只保留在当前 Python 服务进程内存中；服务器不写入配置文件、
  不通过 API 回传 Key，前端提交后清空输入框，也不将其存进浏览器存储。
- 更新其他设置时，空的 Key 输入框表示沿用本次服务已有的 Key。
- 停止服务后，页面提交的 Key 失效，下次启动需要重新填写。若启动环境已经设置
  `AGENTLAB_API_KEY`，服务可在启动时从环境初始化 Key；双击入口不会写入或修改环境变量。

运行任务期间先等待完成或停止当前任务，再修改设置。恢复待审批会话时，需选择
创建该检查点时使用的 provider、模型名和 API 根地址；原执行身份不一致时，Agent
会拒绝恢复。Key 在重启后重新填写，使用相同端点和模型更新 Key 不改变执行身份。

## 查看并批准写入

例如发送：

```text
/write notes/day1.txt 今天学会了工具调用
```

Agent 会停在审批卡片，显示具体工具名、调用 ID 与完整参数。确认文件路径和内容后，
可以勾选需要执行的调用并点击“批准所选并继续”，也可以“全部批准”或“全部拒绝”。
未获批准的写入不会执行；`remember` 保存记忆同样需要批准。

工具路径相对于服务启动时的 `workspace/`；默认不允许访问其外部路径。审批与会话
检查点、工作目录、工具声明和模型身份绑定，新的写入需要新的审批。

如果上次服务在任务中意外退出，界面可能显示“恢复中断会话”。等待旧运行租约释放后，
先检查工作区是否已经发生写入，再执行恢复。恢复会将未知结果记录为失败并结束旧任务，
不会重新执行中断时的工具。随后可以发送新任务。

## 知识库与记忆

进入“知识库”后，可以通过“选择文件”导入本地 UTF-8 `.md`、`.txt` 文档，或使用
“导入示例知识”学习随项目提供的内容。“测试知识检索”用于直接查看匹配片段与来源。
回到对话发送 `/search Agent 工具调用`，可以看到同一索引如何通过工具供 Agent 使用。

检索使用中英文词法 BM25，并非向量检索；可使用文档中的具体关键词改善匹配。
来源列表和结果中的文档/片段编号方便回查原文。

对话中的记忆按会话隔离。例如在同一会话发送 `/remember goal 掌握Agent执行循环`，
批准后再发送 `/recall goal`。结果在服务重启后仍保留，其他会话不会自动读取这份记忆。
“记忆”观察器可以帮助理解这些持久化内容。

## 工具、学习路径与协作实验

“工具箱”展示已注册工具的用途和参数。“学习路径”用于按章节对照源码与实验。
在“协作实验”中，可以执行“运行工作流”和“运行评测”，观察依赖节点和回归结果。
工具的审批、超时、输出限制和 Agent 预算仍由 Python 核心统一执行。

## 本机数据与常见问题

默认会话、消息、事件与知识索引保存在 `.agentlab/agentlab.sqlite3`，工具写出的文件在
`workspace/`。`--data-dir`、`--workspace` 会修改对应位置。可以关闭服务后备份这些
目录；API Key 不在备份中。

| 现象 | 处理方式 |
| --- | --- |
| 浏览器没有自动打开 | 在浏览器访问终端显示的 `http://127.0.0.1:端口/` |
| 提示 8765 被其他应用占用 | 关闭自己确认的占用应用，或用 `serve --port 9876 --open` |
| 服务重启后真实模型不可用 | 在“设置”重新填写 Key，保存后测试连接 |
| 发送自然语言只显示命令指南 | 当前为 Demo；在设置中连接真实模型 |
| 等待审批时无法继续普通对话 | 先批准或拒绝当前检查点 |
| 新导入内容搜不到 | 检查文件是否 UTF-8，并尝试文档内的具体关键词 |
| 缺少 `python3` 或版本过旧 | 安装 Python 3.9+ 后重新双击 |

本界面面向本机个人学习，不提供远程登录、多用户隔离或操作系统沙箱。
